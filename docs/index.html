🗄️ Learn Database School — databases step-by-step

One real schema — a small school management system (students, classes, teachers, marks) — used to teach every database idea with a job to do. Explained like you're five, with school analogies, diagrams and hands-on SQL you can run in a terminal.

🚀 Quick start

Everything runs locally in Docker — nothing to install except Docker itself. 
docker run --name school-db -e POSTGRES_PASSWORD=school -p 5432:5432 -d postgres:16
docker exec -it school-db psql -U postgres
