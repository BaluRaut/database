# 🏫 Learn Database School

Learn databases from the ground up — one small idea at a time, with a real-world
analogy, a diagram and hands-on commands for every lesson.

Companion to the other schools:
[learn-docker-school](https://github.com/BaluRaut/learn-docker-school) ·
[learn-kubernetes-school](https://github.com/BaluRaut/learn-kubernetes-school) ·
[learn-aws-school](https://github.com/BaluRaut/learn-aws-school) ·
[learn-argocd-school](https://github.com/BaluRaut/learn-argocd-school)

## Planned lessons

| # | Topic | Analogy |
|---|---|---|
| 01 | What is a database? Tables, rows, columns | A school register 📒 |
| 02 | SQL basics — SELECT, INSERT, UPDATE, DELETE | Asking the office clerk ☎️ |
| 03 | Keys & relationships (primary, foreign, joins) | Student ↔ class ↔ teacher 🔗 |
| 04 | Data types & constraints | Form fields with rules ✅ |
| 05 | Indexes — why queries get fast | The index at the back of a book 🔖 |
| 06 | Transactions & ACID | Moving money between two piggy banks 🐷 |
| 07 | Normalization & schema design | Tidy filing cabinets 🗄️ |
| 08 | Query plans & EXPLAIN | Reading the GPS route 🗺️ |
| 09 | Backups & restore | Photocopies in the safe 🧾 |
| 10 | Replication & high availability | A substitute teacher on standby 🧑‍🏫 |
| 11 | Postgres in Docker | Database in a lunchbox 🍱 |
| 12 | Postgres on Kubernetes (StatefulSets, PVCs) | The school stays open after a move 🏫 |

Each lesson lives in `lessons/NN-topic/README.md` and uses this repo's own
sample schema (a small school management system).
